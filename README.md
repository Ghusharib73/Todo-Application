# Todo Application

A simple and responsive Todo Application built with **HTML, CSS, and JavaScript**. This project demonstrates basic **CRUD (Create, Read, Update, Delete)** operations through a clean and user-friendly interface.

## Features

* Add new todos
* Display todo items in a table/list
* Edit existing todos
* Delete todos
* Responsive and clean user interface
* JavaScript-based CRUD functionality

## Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and CRUD operations

## Project Structure

```text
Todo-Application/
│
├── index.html
├── style.css
└── script.js
```

## How to Use

1. Enter a todo title in the input field.
2. Click the **Add Todo** button.
3. Use the **Edit** button to update a todo.
4. Use the **Delete** button to remove a todo.

## Purpose

This project was created to practice **JavaScript fundamentals, DOM manipulation, event handling, and CRUD operations** while building a practical web application.
